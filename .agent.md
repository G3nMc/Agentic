# Agentic — AI Coding Agent Platform

Flutter desktop frontend + Python orchestrator backend. Multi-agent workflow
with tool-calling loop, supporting HuggingFace, Ollama, Groq, Gemini,
OpenRouter, and GitHub Models backends.

## Current State & Working Context
- **Codebase Overview**:
  - `OrchestratorManager` (Flutter) manages the Python subprocess lifecycle
    with inactivity timeout (10 min) and absolute ceiling (120 min).
  - `Workflow` (Python) dispatches Router → Shaper → Reasoner → Executor loop
    with followup/affirmation detection and plan-detection heuristics.
  - `ToolRegistry` holds all callable tools with path confinement via
    `PathFilter`, circuit breakers, and audit logging.
  - `project_context.py` reads `.agent.md` and merges into the system prompt.
  - `compactor.py` provides context-window compaction (elide + optional
    summarizer) to prevent silent prompt truncation.
  - `agent_config.py` loads per-role agent configuration (backend, model,
    TPM limit, temperature, max_tokens) from JSON written by the Flutter UI.
  - `TeamSession` / `LeaderAgent` / `Runner` implement team mode: leader
    decomposes tasks into groups, workers run sequentially in subprocesses,
    state tracked in `team_board.md`.
  - `OpenAICompatBackend` is the shared base for Groq, OpenRouter, and
    GitHub Models backends.
  - `policy.py` enforces tool-call policies; `path_filter.py` confines
    filesystem access to the project root.
  - `rate_limit.py` provides TPM-based rate limiting for LLM backends.
  - Individual Flutter service classes per backend (GroqService,
    HuggingFaceService, OpenRouterService, GitHubModelsService) plus
    Ollama management chain (OllamaManager, OllamaPythonManager,
    OllamaService, OllamaGenerateService, OllamaLibraryService).
- **Recent Changes**: Team Mode implementation (leader/worker orchestration,
  team_board.md state tracking, sequential worker runner, recovery logging).
  Per-project `.agent.md` support with settings UI editor and auto-generate
  button in chat input. Context-window compactor for multi-agent workflow.
  Per-role agent configuration (agents.json). Path filter for filesystem
  discovery tools. Tools split into dedicated modules. Rate limiting for
  LLM backends. Team mode tests directory added.
- **Known Issues / Tech Debt**: No automated tests (test/ directory is empty).
  Team mode recovery paths are still being stabilised.
- **Immediate Focus**: Stabilise team mode end-to-end (leader decomposition,
  worker execution, recovery on failure). Polish the agent-context feature.

## Behavioral Rules
- **Must Always**: Run `flutter_analyze` after Dart edits; `python_check` after
  Python edits. Use `read_files` (batch) for 2+ files. Validate before declaring
  done.
- **Must Never**: Ask the user to run validators. Invent tool results. Modify
  files outside the active project root. Use emoji in code comments.

## Communication Style

  Use structured step reports for multi-step implementation.
