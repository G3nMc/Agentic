Phase 1: Database Architecture Foundation

Building the multi-tenant database structure that will support your entire application

Total Time: 2 weeks (42 hours) | Days 1-14

Overview & Goals

This phase establishes the complete database schema with multi-tenant isolation. We'll design tables for users, companies, customers, products, and orders with proper relationships.

Why This First: Your code generator needs the complete schema to generate CRUD operations. Getting this right now saves weeks of refactoring later.
Your Naming Convention Applied:
  • Table names: singular (user, tenant, customer, product, order)
  • Primary keys: TABLE_NAME_ID as INT(10) UNSIGNED AUTO_INCREMENT
  • Foreign keys: INT(10) UNSIGNED to match primary keys
  • Field names: UPPERCASE
Deliverable Output
Complete DB Schema SQL migration files ready to run
Multi-tenant Strategy TENANT_ID on all tables with isolation logic
Base Tables 10-12 core tables with relationships
Code Generator Config JSON/YAML configs for auto-generation

3.2 Order Line (Items)

4 hours
CRITICAL
  • Individual products within each order
  • Quantity, pricing, discounts per line
  • Tax calculation per item
CREATE TABLE order_line ( ORDER_LINE_ID INT(10) UNSIGNED PRIMARY KEY AUTO_INCREMENT, ORDER_ID INT(10) UNSIGNED NOT NULL COMMENT 'Reference to parent order', PRODUCT_ID INT(10) UNSIGNED NOT NULL COMMENT 'Product being ordered', PRODUCT_SKU VARCHAR(100) COMMENT 'SKU at time of order (denormalized)', PRODUCT_NAME VARCHAR(255) COMMENT 'Product name at time of order (denormalized)', QUANTITY DECIMAL(12,3) NOT NULL COMMENT 'Quantity ordered', UNIT_PRICE DECIMAL(12,2) NOT NULL COMMENT 'Price per unit', DISCOUNT_PERCENTAGE DECIMAL(5,2) DEFAULT 0 COMMENT 'Line-level discount', LINE_SUBTOTAL DECIMAL(12,2) NOT NULL COMMENT 'Subtotal before tax', TAX_RATE DECIMAL(5,2) DEFAULT 22.00 COMMENT 'IVA percentage', TAX_AMOUNT DECIMAL(12,2) NOT NULL COMMENT 'Calculated tax amount', LINE_TOTAL DECIMAL(12,2) NOT NULL COMMENT 'Total including tax', NOTES TEXT COMMENT 'Line-specific notes', FOREIGN KEY (ORDER_ID) REFERENCES `order`(ORDER_ID) ON DELETE CASCADE, FOREIGN KEY (PRODUCT_ID) REFERENCES product(PRODUCT_ID), INDEX idx_order (ORDER_ID) );
Denormalization Note: We store PRODUCT_SKU and PRODUCT_NAME in order_line even though they're in product table. This preserves order history if product details change later.

3.4 Database Triggers & Auto-Calculations

3 hours
  • Auto-calculate order totals when lines change
  • Auto-create ORDER_NUMBER sequence per tenant
  • Trigger for order_status_history insertion
DELIMITER $$ CREATE TRIGGER trg_order_line_after_insert AFTER INSERT ON order_line FOR EACH ROW BEGIN UPDATE `order` SET SUBTOTAL = ( SELECT SUM(LINE_SUBTOTAL) FROM order_line WHERE ORDER_ID = NEW.ORDER_ID ), TAX_AMOUNT = ( SELECT SUM(TAX_AMOUNT) FROM order_line WHERE ORDER_ID = NEW.ORDER_ID ), TOTAL_AMOUNT = ( SELECT SUM(LINE_TOTAL) FROM order_line WHERE ORDER_ID = NEW.ORDER_ID ) WHERE ORDER_ID = NEW.ORDER_ID; END$$ CREATE TRIGGER trg_order_line_after_update AFTER UPDATE ON order_line FOR EACH ROW BEGIN UPDATE `order` SET SUBTOTAL = ( SELECT SUM(LINE_SUBTOTAL) FROM order_line WHERE ORDER_ID = NEW.ORDER_ID ), TAX_AMOUNT = ( SELECT SUM(TAX_AMOUNT) FROM order_line WHERE ORDER_ID = NEW.ORDER_ID ), TOTAL_AMOUNT = ( SELECT SUM(LINE_TOTAL) FROM order_line WHERE ORDER_ID = NEW.ORDER_ID ) WHERE ORDER_ID = NEW.ORDER_ID; END$$ CREATE TRIGGER trg_order_line_after_delete AFTER DELETE ON order_line FOR EACH ROW BEGIN UPDATE `order` SET SUBTOTAL = COALESCE(( SELECT SUM(LINE_SUBTOTAL) FROM order_line WHERE ORDER_ID = OLD.ORDER_ID ), 0), TAX_AMOUNT = COALESCE(( SELECT SUM(TAX_AMOUNT) FROM order_line WHERE ORDER_ID = OLD.ORDER_ID ), 0), TOTAL_AMOUNT = COALESCE(( SELECT SUM(LINE_TOTAL) FROM order_line WHERE ORDER_ID = OLD.ORDER_ID ), 0) WHERE ORDER_ID = OLD.ORDER_ID; END$$ CREATE TRIGGER trg_order_status_change AFTER UPDATE ON `order` FOR EACH ROW BEGIN IF OLD.STATUS != NEW.STATUS THEN INSERT INTO order_status_history ( ORDER_ID, OLD_STATUS, NEW_STATUS, CHANGED_BY_USER_ID ) VALUES ( NEW.ORDER_ID, OLD.STATUS, NEW.STATUS, NEW.CREATED_BY_USER_ID ); END IF; END$$ DELIMITER ;
